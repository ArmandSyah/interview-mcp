Before you start

Does this require AWS or a paid AI account?

No. Local practice works without AWS or AI. Ollama runs a model on your computer. Hosted coaching is a separate feature under development.

Does signing in upload my desktop work?

No. Website sign-in does not import or upload desktop drafts, diagrams, or local practice records.

What does this payment preview charge?

Nothing real. This preview uses Paddle sandbox. Live payments need a verified merchant account and a separate launch review.

Can I use this from an editor?

The project also supplies MCP tools. See the repository for local setup and the current hosted preview limits.
